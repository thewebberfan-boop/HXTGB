# 五家期货交易所档案补充记录

核查日期：2026-09-06。项目：HXTGB，端口4000。

## 完成范围与边界

本轮补充中金所、广期所14人的可定位来源与履历摘要，并对上期所、大商所、郑商所8人的档案增加历史岗位或新近活动证据。另将旧名录中的唐宪、吴太明标记为身份待核，撤下无链接支持的学历、出生信息与精确任期。原始旧数据仍在数据文件前部保留，运行时使用核验覆盖层。

这不是“五所全体完整履历已补齐”的验收结论。现有名录共38条，其中36条有结构化来源、2条身份待核。中金所及广期所完整现任名单尚未完成官网交叉核验；蔡建春的董事身份也不能自动算作党委班子身份。有来源不等于全职业生涯已完整。

## 关键质量处理

- 任命、提名、当选、聘任分别表述；不把新闻发布日期当作正式任命日。
- 同名消歧：不合并地方干部高卫兵、财政部及ISSB冷冰等不同身份。
- 高校合作新闻不构成校友或学历证据。
- 游航学士院校保留巴交所英文原文，中文校名尚未确认，不强行映射。
- 无法确定起止时间的历史岗位暂在摘要及来源中呈现，不虚构结束日期来填时间轴。
- 交易所官网部分页面访问超时。未宣称遍历了所有年鉴、所有新闻网站或CNKI/万方全文；本轮没有取得学位论文全文。

## 后续验收条件

1. 获取中金所、广期所完整现任领导名录及发布日期，处理两条待核身份及遗漏成员。
2. 将每人的任职、教育与照片逐项绑定证据；不同职位之间的未知时间保留为空。
3. 扩展数据模型，支持“历史任职存在、起止日期未公开”和活动时间点，避免摘要成为历史履历唯一承载位置。
4. 继续查官方年报、干部任免、学校校友档案及合法可访问的论文元数据；记录未公开或无法访问的渠道。
